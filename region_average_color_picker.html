How it works

  • Pan — default mode, drag to pan and scroll/pinch to zoom.
  • Rectangle — drag out a box on the image.
  • Freehand — draw any closed shape.
  • The average is computed from the image's full-resolution pixels, independent of current zoom level.
  • Images loaded from external URLs need the host to allow cross-origin access for color sampling to work; the image will still display otherwise.
